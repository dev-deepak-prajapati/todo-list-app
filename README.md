# 📝 To-Do List App

A clean, responsive, and easy-to-use To-Do List web application built using **HTML5**, **CSS3**, and **Vanilla JavaScript**. Perfect for keeping track of daily tasks with a beautiful gradient UI.

---

## ✨ Features

- **Add Tasks:** Quickly add new tasks via the input field by clicking the "Add" button or pressing `Enter`.
- **Complete Tasks:** Check off tasks to mark them as completed with a visual strikethrough effect.
- **Edit Tasks:** Modify existing tasks seamlessly using an intuitive prompt dialog.
- **Delete Tasks:** Remove unwanted or finished tasks from your list with a single click.
- **Modern UI/UX:** Styled with smooth gradients (`#eaf4ff` to `#c7e0ff`), clean typography (`Inter`), and modern spacing.

---

## 🛠️ Technologies Used

- **HTML5:** Semantic markup structure.
- **CSS3:** Custom styling, Flexbox layout, and linear gradients.
- **JavaScript (ES6+):** DOM manipulation, event delegation, and dynamic element creation.
